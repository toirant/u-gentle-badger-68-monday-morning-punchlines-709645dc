## The joke

> My bed and Monday morning had a custody hearing. Monday won, so now I only see my dreams on weekends.

## How it works

`main.ts` writes that single line (101 characters) to `/output/entry.txt`, validating first that it is 1–200 characters, a single line, and not only whitespace, then reading it back to confirm the file holds exactly the validated text.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later.
